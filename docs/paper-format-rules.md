# 毕业论文格式检查规则映射

本文件整理了论文格式检查系统中与“电子工程学院2027届毕业论文范本”相对应的规则来源。规则分为以下几类：

## 1. 封面与元数据
- 页面边距
- 题目格式
- 学生信息
- 专业名称完整性
- 签名与日期
- 英文题目大小写与一致性

## 2. 摘要与关键词
- 摘要标题样式
- 摘要字数与内容要素
- 关键词数量与分隔符
- 摘要页码格式

## 3. 目录与章节结构
- 自动目录生成
- 目录标题样式
- 一级/二级/三级标题规范
- 每章另起一页
- 本章小结
- 总结与展望
- 参考文献与致谢章节位置

## 4. 图表与公式
- 图题位置和编号
- 图不能跨页
- 图像清晰度
- 表格三线表
- 表题位置
- 跨页续表
- 公式必须用数学编辑器
- 公式编号规范

## 5. 参考文献与引用
- 引用从 [1] 开始连续编号
- 参考文献数量与结构
- 期刊页码要求
- DOI 清理
- 外文参考文献符号规范
- 学位论文城市前缀要求

## 6. 结论、致谢、附录
- 结论与展望写法
- 致谢章节格式
- 附录是否必要
- 附录正文格式

## 7. 版面与编辑细节
- 图表不超页边距
- 单词不能中间换行
- 删除黄色批注
- 删除范本示例内容
- 最终整篇统一总检查

## 8. 规则实施建议
系统实现时建议使用规则分组管理：

- layout
- cover
- title
- abstract
- chapter
- section
- figure
- table
- citation
- bibliography
- acknowledgement
- appendix
- editorial

这样可以让检查系统在 Web 前端展示时按规则类型筛选，便于老师快速定位问题。
